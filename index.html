How this works
Canadian nominal rates are converted to equivalent monthly rates using semi-annual compounding: monthly rate = (1 + annual/2)^(1/6) − 1.

• Keep initial payment holds the original variable payment constant. If interest exceeds the payment, the shortfall is added to principal (negative amortization).
• Recalculate payment resets the payment after each hike so the remaining balance amortizes over the remaining original amortization period.
Only hikes that fall inside the comparison term affect the interest totals. This is an illustrative model — confirm exact payment rules with the lender.
